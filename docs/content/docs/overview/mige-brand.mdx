# 米格 MIGE

米格是 AI 影像创作工作台，品牌主张为「让脑洞，开拍。」。小猩猩角色名为米酒，承担欢迎和引导；用户作品是创作页面的主要内容。

## 标识与素材

默认头像标为 `/logo.svg`，用于导航、favicon、画布助手小入口和品牌收尾。`/brand/mige-monochrome.svg` 为单色版，可在设计工具中转换为深色或反白。默认关闭 Logo 外框，浅深主题复用同一彩色头像。正式页面字标使用可访问的文本「米格」，英文辅助字标为 MIGE。

`/images/brand/mige-storyboard.png` 为基于参考形象生成的透明插画，用于官网、登录与创作首页。页面指定图片宽高，避免加载后位移；图片为装饰时使用空替代文本，不替代按钮或真实状态。

## 配色

默认皮肤为 `mige-studio`（米格片场），提供完整的浅色、深色、后台与登录配色，采用现有三层设计 token 和 Ant Design 适配。

| 角色 | 色值 | 使用 |
| --- | --- | --- |
| 形象赤陶 | `#B6532E` | Logo 与插画 |
| 操作赤陶 | `#A94727` | 浅色主操作、焦点与链接 |
| 米白 | `#F8F4EB` | 浅色底层与画布 |
| 炭黑 | `#252522` | 浅色正文 |
| 深色底层 | `#1E201F` | 深色工作区与画布 |
| 深色强调 | `#E9A385` | 深色主操作，搭配深色文字 |

普通选中使用低饱和背景，开关和成功仍使用独立绿色状态，危险操作使用红色。不能将所有状态都改成品牌橙。经典黑白保持只读基线，米格片场与其他预置皮肤均可在后台编辑。

## 页面

- `/welcome`：品牌官网，包含角色首屏、故事/画面/画布三种创作入口、创作流程示意和开源致谢。尊重现有欢迎页开放设置；流程示意不是用户真实生成结果。
- `/login`、`/register`、`/forgot-password`：共用品牌插画和表单壳层；管理员配置自定义视频或封面时继续展示对应媒体。
- `/create`：欢迎标题「今天，拍点什么？」，插画与历史入口在输入区上方；小屏隐藏首页装饰插画，保留输入和操作。
- 用户工作区：导航、项目、素材、任务和设置消费同一套语义配色，保留键盘焦点与明暗主题。
- 画布：默认使用中性深色，可切换浅色，保留节点原始比例、连线与现有工具交互。默认助手显示紧凑的米酒头像，不加载原内置角色动画；管理员配置的 Live2D 或动画包继续生效。
- 后台：品牌标识与皮肤跟随公开外观配置，恢复默认操作恢复米格身份。

## 配置与边界

默认身份是 `brandName=米格`、`brandSlug=mige`。品牌插画只在该身份下出现；自定义品牌继续使用自己的标识和原欢迎页。修改默认值不会覆盖数据库里已经保存的自定义外观，已有部署如有保存值需在后台明确选择或恢复默认。

技术标识、仓库名、容器、API、插件协议、浏览器缓存键、既有域名与对象存储路径保留。此次没有新增数据库表或字段，也不移动历史资源。开源作者、贡献者和协议归属继续保留原有署名。
